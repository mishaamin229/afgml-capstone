# Protocol (frozen before inspecting test outcomes)

- **Splits.** Positional 60/20/20 (train/val/test) of the date-ordered release. Binning cut points fixed a priori; BN, fallback tables, thresholds, fallback selection and EOpp thresholds use train/validation only.
- **Primary predictive metric.** Average precision (AP). **Allowed loss.** 0.01 absolute vs exact inference (used to select the fallback on validation; re-checked on test).
- **Primary fairness metric.** ΔEOpp = range of group TPRs, intersections age band × marital. Diagnostics: ΔDP, ΔEOdds, selection-rate ratio, worst-group TPR, fallback-rate gap, group decision flips vs exact, TV distance of posteriors. Groups with < 30 relevant observations are exploratory; `dEOpp` (all groups) and `dEOpp_supported` (≥ 30 positives) are both reported.
- **Operating point.** Capacity 20 % (robustness: 10 %, 30 %); threshold = validation quantile of the *exact* scores of the same workload.
- **Budgets.** Deterministic operation counts (factor-entry multiplications + additions) per query. Levels = {50, 75, 90, 95, 100} % quantiles of natural-validation exact op counts; primary = 75 %. A query *trips* iff exact elimination would exceed the budget; the fallback is then a table lookup. Wall-clock is measured separately (`scripts/profile_latency.py`).
- **Workloads.** `natural` (real `unknown` pattern; **confirmatory**); `dependent` and `independent` synthetic masks (**exploratory, simulated**; same overall masking rate, group-dependent vs group-independent).
- **Methods.** Exact reference; global (prior) fallback; **proposed** (fairness-aware fallback selection); utility-only selection (ablation); threshold adjustment after budgeted inference (Hardt-style, capacity matched); fair-adjusted exact; LR and GBT on the same pre-contact variables.
- **Selection rule (proposed).** Among candidate fallbacks with validation AP loss ≤ tolerance choose the smallest worst-group decision-flip rate vs exact (supported groups); if none qualifies choose the smallest AP loss. Routing uses no group information; `age_prior` (uses A) is flagged.
- **Uncertainty.** Fixed-model **paired moving-block bootstrap** over date-ordered test blocks (length 50, 1,000 replicates, 95 % percentile). Seeds (0–4) cover synthetic masks, synthetic networks and GBT — *algorithmic*, not population, variability; summarised with t-intervals over seeds. The bootstrap statistic is ΔEOpp over **supported** groups (≥ 30 positives in the full test sample, fixed once — `supported_groups`), identical to the reported `dEOpp_supported`; an all-groups version is kept only as a labelled sensitivity. Every stochastic part (main run and all robustness runs) uses all 5 seeds.
- **Confirmatory family (Holm).** `proposed − {global_prior, util_sel, thr_adj_post_budget}` for ΔEOpp on the natural workload. Everything else is exploratory.
- **Correctness.** Exact VE (3 heuristics) vs clique tree (2 heuristics) vs enumeration, all within 1e-6, on real-evidence patterns and masked patterns (`results/metrics/exp1_exact_agreement.json`); unit tests on normalization, scopes, evidence, budgets, leakage and metrics.
