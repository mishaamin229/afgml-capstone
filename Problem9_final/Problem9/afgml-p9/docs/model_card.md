# Model card

- **Purpose.** Offline audit of how an operation-count budget on exact Bayesian-network inference changes outreach decisions across age×marital groups. **Not** a deployment model; no marketing-effect, creditworthiness or eligibility claims.
- **Model.** Dirichlet-smoothed (α = 1, train only) discrete BN with prespecified structure (`configs/model.yaml`); exact VE (min-fill / min-weight / min-degree) and calibrated clique tree; barren-node pruning (exact).
- **Decision rule.** Select if `P(y=1 | evidence) ≥ τ`, τ = validation quantile for the capacity (default 20 %).
- **Fallbacks.** Precomputed lookup tables from the exact BN (prior; `{poutcome, pdays_bin}`; + `{job, housing, loan}`; `age_prior`, which uses the protected attribute). Routing is *group-unaware* (budget trip only). Group labels are used for fallback *selection* on validation data and in the threshold-adjustment baselines at decision time.
- **Protected attribute at prediction time.** The age band is a BN variable and is used as evidence by every BN method (it is the declared protected attribute `A`). `marital` is not used by any model.
- **Intended use / prohibited extrapolation.** Auditing computational-budget effects on a retrospective sample. Do not generalise to uncontacted people, other banks/periods, or other budgets/hardware.
- **Performance, calibration, group metrics.** Generated by `scripts/make_results.py` (`results/tables/`, `results/metrics/`); no numbers are hard-coded here.
- **Limitations.** Small network (exact inference cheap); budget effects depend on network density; synthetic masks and networks are simulated; date-block bootstrap cannot model repeated customers.
